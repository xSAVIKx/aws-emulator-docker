# Security policy

Report a vulnerability in this image or its build through a private
[GitHub security advisory](https://github.com/xSAVIKx/aws-emulator-docker/security/advisories/new),
or send an email to yurii@serhiichuk.dev. Do not open a public issue.

Report a vulnerability in the AWS Emulator itself to AWS. See
[aws/aws-emulator](https://github.com/aws/aws-emulator/security/policy).
